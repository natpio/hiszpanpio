# Hiszpański — aplikacja do nauki

## Uruchomienie
```bash
pip install -r requirements.txt
streamlit run app.py
```

Aplikacja działa lokalnie i zapisuje postęp w `data/user_progress.json`.

### Najważniejsze zmiany
- nowy, produktowy interfejs i responsywny layout,
- ekran startowy z kontynuacją nauki,
- kurs z kartami lekcji i postępem,
- poprawione, jednoznaczne klucze postępu dla wielu sekcji ćwiczeń,
- powtórki SM-2,
- szybki trener słówek,
- ściąga gramatyczna,
- analityka, seria dni i odznaki,
- import/eksport postępu,
- bezpieczniejsze sprawdzanie odpowiedzi (np. akcenty nie blokują poprawnej odpowiedzi).
